```
Nenhuma classe deve ser obrigada a implementar métodos que não utiliza.
```

Prefira várias interfaces pequenas em vez de uma interface enorme.

#### ❌ Exemplo ruim
```
public interface IFuncionario
{
    void Trabalhar();
    
    void Comer();
    
    void Dormir();
}
```

Imagine um robô:
```
public class Robo : IFuncionario
{
    public void Trabalhar() { }

    public void Comer()
    {
        throw new NotImplementedException();
    }

    public void Dormir()
    {
        throw new NotImplementedException();
    }
}
```
O robô foi obrigado a implementar métodos que não fazem sentido.

#### ✅ Exemplo bom
```
public interface ITrabalhador
{
    void Trabalhar();
}

public interface IHumano
{
    void Comer();
    void Dormir();
}
```

Agora:
```
public class Pessoa : ITrabalhador, IHumano
{
}

public class Robo : ITrabalhador
{
}
```
Cada classe implementa apenas o que precisa.
