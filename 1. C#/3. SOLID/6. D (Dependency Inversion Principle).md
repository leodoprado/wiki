Em vez de criar objetos diretamente dentro da classe, utilize interfaces e injeção de dependência.

#### ❌ Exemplo ruim
```
public class PedidoService
{
    private EmailService _email = new EmailService();

    public void FinalizarPedido()
    {
        _email.Enviar();
    }
}
```

Problemas:
- difícil trocar o serviço de e-mail;
- difícil fazer testes;
- alto acoplamento.

#### ✅ Exemplo bom
```
public interface IEmailService
{
    void Enviar();
}

public class EmailService : IEmailService
{
    public void Enviar()
    {
    }
}

public class PedidoService
{
    private readonly IEmailService _email;
    
    public PedidoService(IEmailService email)
    {
        _email = email;
    }
    
    public void FinalizarPedido()
    {
        _email.Enviar();
    }
}
```

Agora você pode usar qualquer implementação:
```
var pedido = new PedidoService(new EmailService());

var pedidoTeste = new PedidoService(new EmailFake());
```
Isso torna o código muito mais flexível e testável.
