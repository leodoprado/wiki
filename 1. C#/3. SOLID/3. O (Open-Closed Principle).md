```
Uma classe deve estar aberta para extensão, mas fechada para modificação.
```

Quando surgir um novo requisito, você deve conseguir adicionar comportamento sem alterar código já existente.

#### ❌ Exemplo ruim
```
public class Desconto
{
    public decimal Calcular(string tipo, decimal valor)
    {
        if (tipo == "Cliente")
            return valor * 0.10m;

        if (tipo == "Funcionario")
            return valor * 0.20m;

        return 0;
    }
}
```
Sempre que surgir um novo tipo, será necessário alterar a classe.

#### ✅ Exemplo bom
```
public interface IDesconto
{
    decimal Calcular(decimal valor);
}

public class DescontoCliente : IDesconto
{
    public decimal Calcular(decimal valor)
        => valor * 0.10m;
}

public class DescontoFuncionario : IDesconto
{
    public decimal Calcular(decimal valor)
        => valor * 0.20m;
}
```

Agora basta criar uma nova implementação.
```
public class DescontoVip : IDesconto
{
    public decimal Calcular(decimal valor)
        => valor * 0.30m;
}
```
Nenhuma classe existente precisou ser alterada.
