```
Uma classe deve ter apenas um motivo para mudar.
```

Cada classe dever ter apenas uma responsabilidade.

#### ❌ Exemplo ruim
```
public class Relatorio
{
    public void Gerar() { }

    public void SalvarNoBanco() { }

    public void EnviarEmail() { }
}
```
Essa classe faz três coisas diferentes.

#### ✅ Exemplo bom
```
public class Relatorio
{
    public void Gerar() { }
}

public class RelatorioRepository
{
    public void Salvar(Relatorio relatorio) { }
}

public class EmailService
{
    public void Enviar(Relatorio relatorio) { }
}
```
Agora cada classe possui apenas uma responsabilidade.
