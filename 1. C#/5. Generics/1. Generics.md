`Generics` é um recurso da linguagem C# que permite criar **classes, métodos, interfaces e outras estruturas capazes de trabalhar com diferentes tipos de dados**, mantendo a segurança de tipos em tempo de compilação.

Em vez de criar uma implementação para cada tipo, é possível definir um **parâmetro de tipo**, representado normalmente pela letra `T`, que será substituído pelo tipo desejado quando utilizado.

Os Generics são amplamente utilizados no .NET, estando presentes em classes como `List<T>`, `Dictionary<TKey, TValue>`, `HashSet<T>` e interfaces como `IEnumerable<T>` e `ICollection<T>`.

---
### 2. Qual problema resolve?

Antes dos Generics, era comum utilizar classes que armazenavam objetos do tipo `object`, permitindo misturar diferentes tipos de dados na mesma coleção.

Isso tornava o código menos seguro, pois era necessário realizar conversões (_casts_) para recuperar os valores.

Os Generics resolvem esse problema permitindo que o compilador conheça o tipo dos dados, evitando conversões desnecessárias e reduzindo a possibilidade de erros.

---
### 3. Como funciona?

Um Generic utiliza um ou mais **parâmetros de tipo**, representados entre os sinais `< >`.

Esses parâmetros funcionam como um espaço reservado para um tipo que será informado quando a classe, método ou interface for utilizada.

Por exemplo:

```
List<string> nomes = new()
{
    "João",
    "Maria",
    "Pedro"
};

List<int> idades = new()
{
    20,
    25,
    30
};
```

Neste exemplo:

- `List<T>` é uma classe genérica.
- O parâmetro `T` foi substituído por `string` na primeira lista.
- O parâmetro `T` foi substituído por `int` na segunda lista.
- A mesma classe pode trabalhar com diferentes tipos de dados sem precisar ser reescrita.

---
### 4. Quando usar?

- Quando deseja reutilizar uma classe ou método para diferentes tipos de dados.
- Quando deseja garantir segurança de tipos em tempo de compilação.
- Quando deseja evitar conversões (_casts_).
- Quando pretende desenvolver componentes reutilizáveis.

Na prática, os Generics estão presentes em grande parte das bibliotecas do .NET e são utilizados sempre que uma estrutura deve funcionar com diferentes tipos de dados.

---
### 5. Exemplo prático

```
List<string> nomes = new();

nomes.Add("João");
nomes.Add("Maria");

foreach (var nome in nomes)
{
    Console.WriteLine(nome);
}
```

Outro exemplo:

```
List<int> numeros = new();

numeros.Add(10);
numeros.Add(20);

foreach (var numero in numeros)
{
    Console.WriteLine(numero);
}
```

Observe que a mesma classe `List<T>` foi utilizada para armazenar tipos diferentes, apenas alterando o parâmetro informado entre `< >`.

---
### 6. Principais conceitos

|Conceito|Descrição|
|---|---|
|`<T>`|Representa um parâmetro de tipo genérico.|
|`TKey`|Representa o tipo da chave em coleções como `Dictionary<TKey, TValue>`.|
|`TValue`|Representa o tipo do valor em coleções como `Dictionary<TKey, TValue>`.|
|Classe Genérica|Classe que utiliza parâmetros de tipo.|
|Método Genérico|Método que utiliza parâmetros de tipo.|
|Interface Genérica|Interface que utiliza parâmetros de tipo.|
|Constraints|Restrições que limitam quais tipos podem ser utilizados como parâmetro.|

---
### 7. Limitações

Apesar de serem extremamente flexíveis, os Generics possuem algumas limitações.

- O tipo deve ser conhecido em tempo de compilação.
- Algumas operações só podem ser realizadas quando existem restrições (_constraints_).
- Nem todos os tipos podem ser utilizados em determinados cenários sem especificar restrições adequadas.

---
### 8. Resumo

- `Generics` permitem criar código reutilizável para diferentes tipos de dados.
- Utilizam parâmetros de tipo, como `T`, `TKey` e `TValue`.
- Aumentam a segurança de tipos em tempo de compilação.
- Eliminam a necessidade de conversões (_casts_) em muitos cenários.
- São amplamente utilizados nas coleções e interfaces do .NET.
